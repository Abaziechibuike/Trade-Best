# TRADE BEST Feature Backlog

## Product Goal
Create a simple online marketplace where local traders can list goods, connect with customers, and manage sales and delivery.

## Priority Legend
- P0 = Critical / Must have for MVP
- P1 = Important / Should have soon
- P2 = Nice to have / Later

## User Stories

### Seller Stories
- As a seller, I want to create a profile so customers can know my business.
- As a seller, I want to list products with images and prices so customers can buy them.
- As a seller, I want to receive orders online so I do not depend only on local foot traffic.
- As a seller, I want to update order status so customers know progress.
- As a seller, I want delivery/waybill support so products can reach customers easily.

### Customer Stories
- As a customer, I want to browse products online so I can find what I need easily.
- As a customer, I want to search for items by category so I can find relevant products quickly.
- As a customer, I want to place an order so I can buy from local businesses without visiting in person.
- As a customer, I want to know delivery details so I know when my product will arrive.

## Definition of Done
A backlog item is considered done when:
- The feature works as expected
- It is tested for basic use cases
- The user can complete the main action without confusion
- The design is readable and usable
- The feature is documented or explained for the team
